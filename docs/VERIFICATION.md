## Reproduce

```sh
npm run check
npm test
npm run readiness
npm run verify:ai
npm run verify:permissions
npm run verify:paypal
npm start
```

Start Ollama and make the configured model available before `verify:permissions` or `verify:ai`. The former exercises the new permission-comparison and clarification flow; the latter checks the older scope classifier. Readiness checks availability only, and `verify:paypal` checks authentication without creating a payment.
